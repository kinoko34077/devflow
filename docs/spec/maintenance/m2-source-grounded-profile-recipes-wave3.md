## 3. Real risk and ownership constraints

1. **Third-party and rights**: IDS CHISE data license/provenance, Jev external API contents, kotonomani image+voice rights, gpt-supervisor (earlier wave) private chat are separate security/data boundaries. Repo-level LOW/MEDIUM tags do not automatically downclassify the component.
2. **Source truth and risk**: Repo Monitor local vs Pages identities, IDS verified vs candidate entries, kotonomani mock approval vs Human approval, Music-Dsl archive vs runtime reader, cora preserved prototype vs accepted main, Jev stable tag vs main all require explicit state differentiation.
3. **No existing owner takeover**: IDS-Composit current Draft writeback and Pages publication, kotonomani #1/#4 Human media approval, Gomoku and 2bit accepted closed repairs, cora #5 historical local branch all retain their own existing owner/gates. This Wave3 did not modify those repos.
4. **Inventory tally**: This *source-specific design candidate* covers 8 distinct repos not in Waves 1–2. Total proposal count is **20 unique managed repos** across all three waves. The historical 51 open Controls observation is not treated as a current census; unknown/not yet profiled repositories remain NOT_DESIGNED/NOT_RUN. Only 3 accepted SMC v1 PILOT catalogs are actual admitted installations; this document creates none.
5. **No new runtime work**: does not enable supply, publish audit run, configure cron/claim/secret, copy private data, deploy Pages or GitHub Project, or assert current end-user hardware/browser proof. Existing #209 PILOT authority, M5 source-based next-run gate and M6 staged admission remain unchanged.
