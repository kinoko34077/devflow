## Human cleanup — two independent actions
The script enters this owner-cleanup flow even if the Device Flow polling errors, expires, never yields a usable bearer, or returns a malformed token. In no-token cases it cannot prove a token was revoked; it reports `OWNER_CLEANUP_ATTESTED_NO_TOKEN` only after both owner confirmations. Without confirmations, `CLEANUP_UNVERIFIED` remains. Treat all owner attestations as unverified externally.
When the local process asks for the following, the owner must use their own GitHub browser. A token's HTTP 401 is evidence of revocation only if that **same bearer previously authenticated** the fixed user via `GET /user`. Malformed/non-user/unobserved issued tokens receive `CLEANUP_UNVERIFIED` even if the owner completes both cleanup confirmations. Poll errors, timeouts and non-200 responses after an attempted authorization still require both owner cleanup steps:
1. Revoke **Authorized GitHub Apps user authorization** at `https://github.com/settings/connections/applications` and enter **`AUTHORIZATION_REVOKED`** locally.
2. Uninstall the **temporary test GitHub App installation** at `https://github.com/settings/installations`, only for this canary, and enter **`APP_UNINSTALLED`** locally. Optionally delete the temporary App in the owner settings. Do not alter the ChatGPT GitHub connector.
3. The same original token must then yield `GET /user` **401** as an access-token revocation check. A 401 does not independently prove installation removal or refresh-token grant revocation: owner attestation is explicitly recorded as **not independently verified**. Either missing attestation, 200/token still valid, timeout, failed cleanup, or unverified refresh-token status means `CLEANUP_UNVERIFIED` (not successful teardown). No automatic token/permission escalation.
4. The code explicitly discards the optional OAuth refresh token field and does not persist credentials. User must keep the terminal private; **do not invoke this credential-bearing flow through RDC** where user/device/token details could enter tool transcripts.
